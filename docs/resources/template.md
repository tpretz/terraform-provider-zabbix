# zabbix_template (Resource)

Manages a Zabbix template: a reusable collection of items, triggers, graphs and discovery rules that can be linked to many hosts.

## `groups` means different things on different servers

On Zabbix 6.2 and later, `groups` holds **template** group ids
([`zabbix_templategroup`](templategroup)). On 6.0 and 6.1, template groups do
not exist and it holds host group ids ([`zabbix_hostgroup`](hostgroup)). The id
spaces are disjoint, so a configuration written for one will not apply to the
other — see
[MIGRATING.md § 5](https://github.com/tpretz/terraform-provider-zabbix/blob/v2/MIGRATING.md#5-zabbix_templategroups-now-means-template-groups).

## Version-gated attributes

| Attribute | Requires |
|---|---|
| `vendor_name`, `vendor_version` | Zabbix 6.4 — and must be set together |
| `readme`, `wizard_ready` | Zabbix 7.4 |

These are refused rather than silently dropped on an older server: from Zabbix
7.0 an unknown object property is a hard API error, and a value quietly
discarded is worse than one rejected.

## Example Usage

```terraform
resource "zabbix_templategroup" "applications" {
  name = "Templates/Applications"
}

resource "zabbix_template" "example" {
  host        = "example-application"
  name        = "Example application"
  description = "Managed by Terraform"
  groups      = [zabbix_templategroup.applications.id]

  macro {
    name  = "{$APP.PORT}"
    value = "8080"
  }
}
```

## Schema

### Required

- `groups` (Set of String) Group IDs this template belongs to. On Zabbix 6.2 and later these are template group ids (zabbix_templategroup); on 6.0/6.1 they are host group ids (zabbix_hostgroup).
- `host` (String) Technical template name, unique across the Zabbix server

### Optional

- `description` (String) Template description
- `macro` (Block Set) User macros defined on this object (unordered). Zabbix replaces the whole macro collection on update, so omitting a macro removes it. (see [below for nested schema](#nestedblock--macro))
- `name` (String) Template display name. Defaults to the value of `host`
- `readme` (String) Template readme text, shown by the template wizard. Requires Zabbix 7.4 or later.
- `templates` (Set of String) IDs of templates linked into this one, so their items and triggers are inherited
- `vendor_name` (String) Template vendor name. Requires Zabbix 6.4 or later, and must be set together with vendor_version.
- `vendor_version` (String) Template vendor version. Requires Zabbix 6.4 or later, and must be set together with vendor_name.
- `wizard_ready` (Boolean) Whether the template is ready to be offered by the template wizard. Requires Zabbix 7.4 or later.

### Read-Only

- `id` (String) The ID of this resource.
- `uuid` (String) Template UUID, generated by Zabbix
