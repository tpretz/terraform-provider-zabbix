# zabbix_graph (Resource)

Manages a Zabbix graph: a named plot of one or more items on a host or template.

## Items are a set

A graph's items are an unordered collection — the drawing order is carried by
`sortorder`, not by the order the blocks appear in — so `item` is a `TypeSet`
and cannot be indexed. Zabbix's return order for graph items changed in 8.0,
which is exactly why the provider does not model it as a list.

## Example Usage

```terraform
data "zabbix_host" "example" {
  host = "server-1.example.com"
}

resource "zabbix_item_agent" "cpu_user" {
  hostid    = data.zabbix_host.example.id
  name      = "CPU utilisation, user"
  key       = "system.cpu.util[,user]"
  valuetype = "float"
}

resource "zabbix_item_agent" "cpu_system" {
  hostid    = data.zabbix_host.example.id
  name      = "CPU utilisation, system"
  key       = "system.cpu.util[,system]"
  valuetype = "float"
}

resource "zabbix_graph" "cpu" {
  name   = "CPU utilisation"
  width  = "900"
  height = "200"
  type   = "stacked"

  # item is a set: sortorder carries the drawing order, not block position
  item {
    itemid    = zabbix_item_agent.cpu_user.id
    color     = "1A7C11"
    sortorder = "0"
  }

  item {
    itemid    = zabbix_item_agent.cpu_system.id
    color     = "F63100"
    sortorder = "1"
  }
}
```

## Schema

### Required

- `height` (String) Graph height in pixels
- `item` (Block Set, Min: 1) Items plotted on this graph. Unordered - set `sortorder` to control the drawing order. (see [below for nested schema](#nestedblock--item))
- `name` (String) Name of the graph, as shown in the frontend
- `width` (String) Graph width in pixels

### Optional

- `do3d` (Boolean) Draw pie and exploded graphs in 3D
- `legend` (Boolean) Show the graph legend
- `percent_left` (String) Left y-axis percentile line, 0 to disable. Normal graphs only
- `percent_right` (String) Right y-axis percentile line, 0 to disable. Normal graphs only
- `type` (String) Graph style, one of: exploded, normal, pie, stacked
- `work_period` (Boolean) Shade non-working time, as configured in Zabbix's working-time setting
- `ymax` (String) Fixed maximum value of the y axis. Applies only when ymax_type is "fixed"
- `ymax_itemid` (String) Item whose last value sets the maximum of the y axis. Applies only when ymax_type is "item"
- `ymax_type` (String) Where the maximum of the y axis comes from, one of: calculated, fixed, item (see ymax and ymax_itemid)
- `ymin` (String) Fixed minimum value of the y axis. Applies only when ymin_type is "fixed"
- `ymin_itemid` (String) Item whose last value sets the minimum of the y axis. Applies only when ymin_type is "item"
- `ymin_type` (String) Where the minimum of the y axis comes from, one of: calculated, fixed, item (see ymin and ymin_itemid)

### Read-Only

- `id` (String) The ID of this resource.

### Nested Schema for `item`

Required:

- `color` (String) Line colour as a six-digit hex RGB string, e.g. "00AA00"
- `itemid` (String) ID of the item to plot

Optional:

- `drawtype` (String) How the item is drawn, one of: bold, dashed, dot, filled, gradient, line. Normal and stacked graphs only
- `function` (String) Value drawn for each point when several data points fall in one pixel, one of: all, average, last, max, min
- `sortorder` (String) Drawing order within the graph, lowest first. This is what carries order, not the position of the block
- `type` (String) How this item contributes to the graph, one of: simple, sum. "sum" applies to pie and exploded graphs only
- `yaxis_side` (String) Which y axis the item is plotted against, one of: left, right

- `id` (String) Graph item ID (gitemid, internally generated)
