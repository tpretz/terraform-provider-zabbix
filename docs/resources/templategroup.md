# zabbix_templategroup (Resource)

Manages a Zabbix template group.

Zabbix 6.2 split template groups out of host groups into a separate entity with
its own ID space. Templates must be placed in a template group rather than a
host group, so `zabbix_template.groups` expects IDs produced by this resource.

On Zabbix versions older than 6.2 this resource transparently uses the host
group API, so the same configuration works across versions.

## Example Usage

```terraform
resource "zabbix_templategroup" "example" {
  name = "Templates/My Application"
}

resource "zabbix_template" "example" {
  host   = "my-application"
  groups = [zabbix_templategroup.example.id]
}
```
