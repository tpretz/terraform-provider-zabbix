# zabbix_item_http (Resource)

Manages a Zabbix HTTP agent item: a value collected by making an HTTP request from the server or proxy.

## Example Usage

```terraform
data "zabbix_host" "example" {
  host = "server-1.example.com"
}

resource "zabbix_item_http" "healthcheck" {
  hostid    = data.zabbix_host.example.id
  name      = "Application health"
  key       = "app.health"
  url       = "https://app.example.com/healthz"
  valuetype = "text"
  delay     = "30s"

  request_method = "get"
  status_codes   = "200"
  timeout        = "5s"

  headers = {
    Accept = "application/json"
  }
}
```

## Schema

### Required

- `hostid` (String) ID of the host or template this item belongs to. Changing it replaces the item
- `key` (String) Item key, unique per host, e.g. `system.cpu.load[all,avg1]`
- `name` (String) Item name, as shown in the frontend
- `url` (String) url to probe
- `valuetype` (String) Type of the value Zabbix stores, one of: float, character, log, unsigned, text. Changing it after data has been collected leaves the old history behind

### Optional

- `auth_type` (String) HTTP auth type, one of: basic, kerberos, none, ntlm
- `delay` (String) How often the item is polled, as a time suffix string, e.g. "1m". Supports Zabbix's flexible and scheduling interval syntax
- `follow_redirects` (Boolean) follow http redirects
- `headers` (Map of String) HTTP headers to send with the request, as a name-to-value map. Zabbix replaces the whole header collection on update, so omitting a header removes it.
- `history` (String) How long Zabbix keeps raw history for this item, as a time suffix string, e.g. "90d". "0" disables history
- `interfaceid` (String) ID of the host interface to poll through. "0", the default, means no interface: it is the only value a template accepts, and it is what item types Zabbix does not poll through an interface use. An item on a host that has interfaces must name one of them -- Zabbix rejects "0" there, and rejects the property being omitted as well
- `password` (String, Sensitive) Authentication Password
- `post_type` (String) HTTP post type, one of: json, raw, xml
- `posts` (String) POST data to send in request
- `preprocessor` (Block List) Preprocessing steps, applied in the order written. This is a list rather than a set precisely because that order is semantic: Zabbix feeds each step the output of the previous one. (see [below for nested schema](#nestedblock--preprocessor))
- `proxy` (String) HTTP proxy connection string
- `request_method` (String) HTTP request method, one of: get, head, post, put
- `retrieve_mode` (String) HTTP retrieve mode, one of: body, both, headers
- `status_codes` (String) http status code
- `tag` (Block Set) Tags applied to this object (unordered). Tags are how Zabbix 5.4 and later group and filter objects; they replaced applications. Zabbix replaces the whole tag collection on update, so omitting a tag removes it. (see [below for nested schema](#nestedblock--tag))
- `timeout` (String) http request timeout
- `trends` (String) How long Zabbix keeps hourly trends for this item, e.g. "365d". "0" disables trends, and is the only valid value for text and log items. Defaults to "365d", or "0" for text and log
- `username` (String) Authentication Username
- `verify_host` (Boolean) https verify host
- `verify_peer` (Boolean) https verify peer
