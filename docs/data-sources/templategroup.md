# zabbix_templategroup (Data Source)

Looks up a Zabbix template group by name.

Template groups are a separate entity from host groups on Zabbix >= 6.2. On
older versions this data source falls back to the host group API.

## Example Usage

```terraform
data "zabbix_templategroup" "existing" {
  name = "Templates/Operating systems"
}

resource "zabbix_template" "example" {
  host   = "my-application"
  groups = [data.zabbix_templategroup.existing.id]
}
```
